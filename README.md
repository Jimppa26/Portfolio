# Jim Valikainen - Personal Portfolio

A bilingual (English / Finnish) personal portfolio website hosted on GitHub Pages.

**Live Site:**[https://jimppa26.github.io/Portfolio/](https://jimppa26.github.io/Portfolio/)

## Features

- **Bilingual Interface:** Language switching between English ('index.html') and Finnish ('index-fi.html')
- **Optimized Design:** Fully optimized for mobile, tabet and desktop
